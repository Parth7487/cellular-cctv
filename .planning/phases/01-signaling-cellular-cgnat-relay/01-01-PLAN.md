<task type="auto">
  <name>Task 2: Implement WebSocket signaling hub with room management</name>
  <files>server/src/signaling.js, server/src/index.js</files>
  <read_first>server/package.json</read_first>
  <action>
    Build `server/src/signaling.js` exporting `createSignalingServer(httpServer)`:
    - Maintains in-memory `Map<roomId, Set<WebSocket>>` room registry.
    - Each WebSocket connection tracks `peerId`, `roomId`, and `role` ('camera' or 'viewer').
    - Handles message types:
      1. `join`: assigns peer to roomId with role; notifies existing peers with `peer_joined`.
      2. `offer`: forwards SDP offer to other peers in the room.
      3. `answer`: forwards SDP answer to other peers in the room.
      4. `candidate`: forwards ICE candidate payload to other peers in the room.
      5. `command`: forwards remote hardware/siren commands to camera peer.
      6. `ping`: replies with `pong` for connection keepalive.
    - On socket close/error: cleans up peer from room, broadcasts `peer_left` to remaining peers, and prunes empty rooms.
    Build `server/src/index.js` to create the HTTP server, attach `createSignalingServer`, load `.env`, and start listening on `PORT || 8080`.
  </action>
  <verify>node -e "import('./server/src/signaling.js').then(() => console.log('OK'))"</verify>
  <acceptance_criteria>
    - server/src/signaling.js exports createSignalingServer
    - Handles offer, answer, candidate, and command routing
    - server/src/index.js starts HTTP and WebSocket listeners
  </acceptance_criteria>
  <done>Signaling hub routes messages accurately between room participants.</done>
</task>
